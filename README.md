# Matematyka od zera — landing page demo

Responsive static landing page in Polish for a single digital workbook.

## Files
- `index.html`: landing page
- `style.css`: responsive styling
- `script.js`: interactive elements and checkout placeholder
- `assets/ebook-mockup.png`: product mockup image (upload locally to complete the repository)

## Preview locally
Open `index.html` in a browser or use a static server.

## Before publishing
- Set the actual price in `index.html` (replace `[UZUPEŁNIJ]`).
- Set `CHECKOUT_URL` in `script.js` to the real checkout URL.
- Replace footer placeholders with seller/contact/legal pages.
- Confirm fulfillment and consumer-rights wording.
- The paid PDF is intentionally not included.

## Netlify
Deploy from GitHub branch `main`. No build command is required; publish the repository root.
